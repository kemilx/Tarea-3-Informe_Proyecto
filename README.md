# Catálogo de anime

Este es un CRUD básico para guardar un catálogo de anime. Fue realizado con
ASP.NET Core, Entity Framework Core y SQL Server LocalDB.

El proyecto permite:

- Agregar anime.
- Ver el catálogo.
- Buscar por título o género.
- Editar registros.
- Eliminar registros.
- Consultar estadísticas.
